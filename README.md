**🎮 Игра «Крестики-нолики» (Tic-Tac-Toe)**

Добро пожаловать в классическую игру «Крестики-нолики», реализованную на платформе Windows Forms (C#). Это простой и понятный проект, который отлично подходит для демонстрации базовой логики работы с интерфейсом и обработкой событий.

**📌 Описание игры**

Это пошаговая игра для двух игроков на одном устройстве. Главная цель — первым собрать непрерывную линию из трех своих символов (крестиков или ноликов). Линия может быть горизонтальной, вертикальной или диагональной.
Игровое поле представляет собой сетку 3×3.

**🚀 Как играть**
1. Старт игры: При запуске программы игровое поле пустое. Право первого хода по умолчанию принадлежит игроку, играющему за «X».

3. Процесс: Чтобы сделать ход, просто кликните левой кнопкой мыши по любой свободной клетке. Выбранный символ появится в клетке, а нажатая кнопка заблокируется.

Смена хода: После каждого хода программа автоматически передает очередь другому игроку. Текущий игрок отображается в специальном индикаторе в нижней части окна.

Завершение раунда:

Победа: Если один из игроков выстроил три своих символа в ряд, игра останавливается, появляется сообщение о победе, а все клетки блокируются.

Ничья: Если все 9 клеток заполнены, но победной комбинации нет, программа объявляет ничью.

Сброс: В любой момент (или после окончания раунда) можно нажать кнопку «Начать заново». Это очистит поле и сбросит счетчик ходов, возвращая игру в исходное состояние.

🛠️ Технические особенности
В проекте реализована следующая логика:

Использование двумерного массива кнопок (Button[,]) для удобной проверки выигрышных комбинаций.

Отдельные методы для проверки строк, столбцов и диагоналей (CheckRows, CheckColumns, CheckDiagonals).

Блокировка уже использованных ячеек для предотвращения случайных повторных нажатий.

Динамическое обновление интерфейса (метки текущего хода и сообщения о результате).

💻 Как запустить
Склонируйте репозиторий или скачайте архив с проектом.

Откройте файл решения TicTacToe.sln в Microsoft Visual Studio.

Нажмите F5 или кнопку «Пуск» (Start), чтобы собрать и запустить игру.
